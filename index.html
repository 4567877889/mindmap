📖 绪 论 Introduction
▾
▾ 一、分离过程的基本概念 基础概念
基础 分离过程：将混合物分成组成互不相同的两种或几种产品的操作。需要分离剂（能量或物质）和分离设备。
基础 广义分离过程三要素：原料（混合物）、产品（组成不相同）、分离设备（装置）、分离剂（能量或物质）。
基础 分离工程：化学工程的分支，研究工业规模上混合物分离的技术科学问题，包括过程原理、方法选择、设备选型、过程模拟、设备设计、系统节能、集成优化等。
▾ 二、分离过程分类 ⭐⭐⭐
核心 传质分离分为：机械分离、平衡级分离（本课程重点）、速率控制分离（膜分离、分子蒸馏等）。
核心 平衡分离过程特点：①引入"相"概念，需产生或加入新相（分相）；②分离原理：平衡时各组分在相间分配不同；③受热力学平衡条件限制，常采用多级分离（塔器）。
重点 分离剂：能量分离剂（ESA）—传入/传出系统的热、输入输出功、减压；质量分离剂（MSA）—吸收剂、萃取剂、吸附剂等。
重点 典型的平衡级分离单元操作：闪蒸、精馏、萃取精馏、吸收蒸出、吸收、蒸出、共沸精馏、液液萃取、固体干燥、蒸发、结晶、浸取、泡沫分离、吸附分离、离子交换、色谱分离。 📄见PPT
基础 速率分离过程特点：分离剂为强制力（压力梯度、温度梯度、电场、磁场）或选择性膜；分离原理为组分在均相中传递（扩散）速率差异。
▾ 三、化工分离过程的特点及发展方向 了解
了解 分离是化工过程必不可少的环节！分离操作占设备投资和能耗的很大比例。
了解 近代分离过程发展方向：①与过程系统工程结合，降低成本；②分离耦合技术、反应与分离耦合技术；③与过程强化、节能技术结合；④新型分离方法不断出现；⑤CO₂减排对分离技术提出更高要求。见PPT 绪论-第12页
⚖️ 第一章 单级平衡过程 Single-stage Equilibrium
▾
▾ 第一节 汽液相平衡 (VLE) ⭐⭐⭐
核心 相平衡反映过程进行的极限，是平衡级分离过程数学模型的重要组成部分。见PPT §1-1
难点 相平衡条件（判据）：T^L = T^V, p^L = p^V, μ_i^L = μ_i^V (i=1,2,…,c)等价于逸度判据：f̂_i^L = f̂_i^V 📄见PPT
核心 Gibbs相律：f = C − π + 2
重点 相平衡关系表示方法：相图（二元/三元体系）、相平衡常数K、分离因子α（相对挥发度）。
核心 Antoine关联方程（单组分饱和蒸汽压）：lg p^s = A − B/(C + T) 📄见PPT
重点 相平衡常数K的计算方法：K_i = y_i / x_i
核心 逸度系数/逸度系数模型（状态方程法）：用同一状态方程计算汽液两相逸度系数。K_i = φ̂_i^L / φ̂_i^V适用于高压体系。 📄见PPT
重点 逸度系数计算式：ln φ̂_i = (1/RT)∫_V^∞ [(∂p/∂n_i)_{T,V,n_{j≠i}} − RT/V] dV − ln Z
重点 常用状态方程：SRK、PR（立方型三参数状态方程）。
核心 逸度系数/活度系数模型（活度系数法）：K_i = γ_i f_i^{∘L} / (φ̂_i p)汽相逸度用逸度系数计算，液相逸度用活度系数计算。 📄见PPT
核心 完整K模型：K_i = (γ_i p_i^s φ_i^s / (φ̂_i p)) · exp[V_i^L(p − p_i^s)/(RT)]
重点 常用的活度系数模型：Wilson（不能用于液液平衡）、NRTL（含水物系精度好）、UNIQUAC（分子大小差别大的物系）、UNIFAC（估算型）。
核心 相对挥发度（分离因子）α_{ij} = K_i / K_j，α=1时无法用普通精馏分离。
重点 简化K模型：K_i = p_i^s / p（理想体系）；K_i = γ_i p_i^s / p（汽相理想、液相非理想）。
重点 K计算方法选择：中低压非理想物系→活度系数法；非极性组分（烃类）→SRK/PR方程；高压极性组分→尚无可靠方法。ASPEN PLUS推荐RK组合模型（RK-Wilson, RK-NRTL等）。 📄见PPT
▾ 第二节 多组分物系泡露点计算 ⭐⭐⭐
核心 泡点方程：∑K_i x_i = 1（已知p, x，求T, y）；露点方程：∑y_i / K_i = 1（已知p, y，求T, x）。
重点 简化K模型泡点温度计算（Newton法）：F(T) = ∑K_i x_i − 1.0，T^{(k+1)} = T^{(k)} − F(T)/F'(T) 📄见PPT
难点 严格K模型的双层循环迭代法：外循环迭代温度T；内循环迭代汽相组成y_i。📄见PPT
重点 泡点压力计算：p_{泡} = ∑p_i^s x_i（理想）；p_{泡} = ∑γ_i p_i^s x_i（液相非理想）。压力迭代：p^{(k+1)} = p^{(k)} ∑K_i x_i
▾ 第三节 闪蒸计算 ⭐⭐⭐
核心 闪蒸：连续、稳态、基于单级汽液平衡的单元操作，常用于混合物粗分离和热量回收。类型：部分汽化、部分冷凝、绝热闪蒸。
核心 MESH方程组：M-物料平衡 Fz_i = Vy_i + Lx_i；E-相平衡 y_i = K_i x_i；S-归一 ∑x_i = 1, ∑y_i = 1；H-热量平衡 FH_F + Q = VH_V + LH_L 📄见PPT
核心 Rachford-Rice (R-R) 闪蒸方程：∑(K_i − 1)z_i / [(K_i − 1)e + 1] = 0，其中 e = V/F 📄见PPT
重点 等温闪蒸：已知T,p，用Newton法求解R-R方程求e（汽化分率）。部分汽化/部分冷凝：指定e或T，迭代另一个变量。
难点 绝热闪蒸：两变量（T和e）同时收敛，用Newton法求解非线性方程组。需计算Jacobian矩阵。F₁(e,T) = ∑(K_i−1)z_i/[(K_i−1)e+1] = 0，F₂(e,T) = eH_V + (1−e)H_L − H_F = 0 📄见PPT
重点 闪蒸自由度分析：压力指定后，只能指定一个设计变量。e=V/F为汽化分率。
🏗️ 第二章 多组分精馏 Multicomponent Distillation
▾
▾ 第一节 自由度分析与设计变量选择 ⭐⭐⭐
核心 自由度：N_f = N_V − N_E（变量数−方程数）。设计变量数：N_D = N_V − N_E
重点 过程变量包括：强度变量（T, p, x, y）、广度变量（Q, F, V, L）、设备参数（N板数, N_F进料位置）。中间变量（如K_i, R）不参与自由度分析。
重点 设计变量 = 限定性设计变量（N_S）+ 非限定性设计变量（N_a）。
重点 一个流股的变量数 = c + 2（p, T, F, x_i）。
核心 郭氏法（郭慕孙, 1956）— 系统进行化工单元及装置自由度分析的方法。
重点 单元自由度分析示例（再沸器）：流股变量数3(c+2)，外界换热1变量→N_V=3c+7；约束关系（MB 2个+EB 1个+E c个+S 1个）→N_E=2c+3；N_D=c+4。 📄见PPT
重点 装置自由度：N_D^u = ∑N_D^e + N_r − N_{uc}。N_r为流股重复使用的约束增加数。
核心 简单精馏塔设计变量指定方案（常用）：进料、每级压力、全凝器压力、回流分配器压力、总理论级数、进料位置、回流温度、馏出液流量、回流比。N_D = 5
难点 复杂塔：每增加1股进料→增加c+2个流股变量+1个进料位置变量；每增加1股侧线→增加1个流量+1个采出位置变量。复杂度随自由度增加呈指数增长。
▾ 第二节 多组分精馏塔的简捷设计 (F-U-G) ⭐⭐⭐
核心 Fenske-Underwood-Gilliland（F-U-G）近似设计法称为简捷法（shortcut method）。
核心 关键组分：LK轻关键组分（控制塔顶产品），HK重关键组分（控制塔底产品）。分离要求指定LK和HK的回收率。
重点 非关键组分：LNK（轻非关键）、HNK（重非关键）、MC（中间组分）。分配组分与非分配组分。清晰分割与非清晰分割。
核心 Fenske方程（全回流、最小理论塔板数）：N_{min} = lg[(x_{LK}/x_{HK})_D(x_{HK}/x_{LK})_B] / lg(α_{LK,HK})_{avg}
核心 Underwood方程（最小回流比）：∑(α_i x_{i,F}) / (α_i − θ) = 1 − q（求θ），R_{min} + 1 = ∑(α_i x_{i,D}) / (α_i − θ)
重点 适宜操作回流比：R = (1.1 ~ 2.0) R_{min}。优化：总费用（操作费+设备费）最小处。 📄见PPT
重点 Gilliland关联式：由R, R_{min}, N, N_{min} 的关系图或拟合式确定理论塔板数N。
重点 Kirkbride关联式：确定进料位置（原则：热力学第二定律，进料位置应使进料级处汽液相组成与进料组成最接近）。
重点 塔压确定原则：①公用工程条件；②混合物热力学性质（临界、分解、结焦等）。塔类型：常压、加压、减压。
重点 冷凝器类型：全凝器、分凝器、混合冷凝器。再沸器类型：卧式再沸器（Kettle-type）、虹吸式再沸器。
核心 简捷法计算步骤：规定进料→规定关键组分回收率→估计非关键组分分配→物料衡算→确定塔压→计算T_D, T_B, α_m→计算N_{min}（Fenske）→计算非关键组分分配→计算R_{min}（Underwood）→R=(1.2~2)R_{min}→Gilliland求N→计算进料位置→Q_C, Q_R计算。 📄见PPT
重点 简捷设计举例：五组分轻烃混合物（丙烷/异丁烷/正丁烷/异戊烷/正戊烷），LK=异丁烷（回收率98%），HK=正丁烷（回收率98%）。 📄见PPT
▾ 第三节 精馏塔内参数分布与分析 ⭐⭐
重点 参数分布：汽液相中组分浓度分布、温度分布、汽液相流量分布。 📄见PPT
重点 多组分精馏中关键组分浓度有极大值，非关键组分可能存在恒浓区域。温度由组成决定，沿塔向下重组分增多，温度升高。
重点 汽液相流量由热量决定（潜热控制），恒摩尔流假设对大多数物系适用。温度分布反映组成，流量分布反映热量变化。
▾ 第四节 多组分精馏的严格模拟 ⭐⭐⭐
核心 平衡级概念：将精馏塔视为由若干平衡级（理论塔板）构成。两个假设：平衡级、全混级。 📄见PPT
核心 通用精馏模型塔——考虑各种实际塔形式，MESH方程组通用：M-物料平衡、E-相平衡、S-求和、H-热量平衡。
重点 MESH方程：F_j z_{ij} + L_{j-1} x_{i,j-1} + V_{j+1} y_{i,j+1} = (V_j+G_j) y_{ij} + (L_j+U_j) x_{ij}
y_{ij} = K_{ij} x_{ij}
∑x_{ij}=1, ∑y_{ij}=1
F_j H_{F_j} + L_{j-1} h_{j-1} + V_{j+1} H_{j+1} = (V_j+G_j) H_j + (L_j+U_j) h_j + Q_j
难点 BP法（泡点法）：方程解耦法。将MESH方程组解离为ME方程（工作方程）+ S方程和H方程（收敛检验）。迭代变量：T_j和V_j。内层T-迭代（泡点），外层V-迭代（热量平衡）。 📄见PPT
🔬 第三章 特殊精馏 Special Distillation
▾
▾ 第一节 概述 ⭐⭐⭐
核心 特殊精馏概念：在物系中加入第三组分（物质分离剂），改变被分离组分间的相对挥发度或热力学平衡关系，用精馏方法实现混合物分离。
重点 采用特殊精馏的情况：①普通精馏不经济（α<1.05, 沸点差<3℃, 塔板>200, 回流比>15）；②普通精馏不可能（共沸体系）。
重点 主要特殊精馏方法：萃取精馏、加盐精馏、变压精馏、均相/非均相共沸精馏、反应精馏、膜精馏、吸附精馏。
重点 特殊精馏的复杂性：①物质分离剂选择（非唯一）；②高度非理想体系相平衡模型；③分离剂回收和再循环（多塔+物流循环）。 📄见PPT
▾ 第二节 共沸精馏 ⭐⭐⭐
核心 共沸现象：汽液平衡时组分在液相和汽相中的组成相等。共沸点处 α=1, T_{bubble}=T_{dew}。共沸物具有压力依赖性。
难点 共沸物的形成：与理想溶液的偏差导致。最大正偏差→最低共沸物；最大负偏差→最高共沸物。 📄见PPT
难点 共沸组成计算：同泡点计算。联立求解：p = γ₁ x₁ p₁^s + γ₂ x₂ p₂^s，x₁ + x₂ = 1，γ_i = f_i(T, x_i)
核心 变压精馏（PSD）：利用不同压力下共沸组成的变化，通过两塔流程（高压塔+低压塔）绕过共沸点限制。两塔间有共沸物循环。 📄见PPT
重点 循环量D₂计算：D₂ = F(z₁−x₁,W₁)(x₁,W₂−x₁,D₁) / [(x₁,W₂−x₁,D₁)(x₁,D₂−x₁,D₁)]。循环量是系统技术经济指标，影响能耗和操作费用。两塔间需进行热集成。
重点 二元非均相共沸精馏：利用分相器（decanter）使塔顶冷凝的共沸物自发分相，绕过共沸点限制。 📄见PPT
难点 非均相共沸精馏流程设计步骤：①绘制T-x-x-y相图；②确定分离区域和分相操作温度；③确定分相后两液相状态点；④确定不同精馏区域分离产品；⑤画出分离流程图。 📄见PPT
核心 三元共沸精馏：加入共沸剂（第三组分），与原组分形成新共沸物。关键工具：三角形坐标图、残余曲线图（RCM）。 📄见PPT
难点 残余曲线图（RCM）：表达三组分混合物简单蒸馏过程中釜液组成变化的曲线。特殊点：不稳定节点、稳定节点、鞍形节点。精馏边界不可跨越。 📄见PPT
重点 共沸剂选择原则：对于二元最低共沸物→选择低沸点组分或能形成新最低共沸物的组分；对于最高共沸物→选择高沸点组分。残余曲线必须连接期望产品。
重点 举例（丙酮为共沸剂分离环己烷-苯）：先混合后分离，将困难转嫁到环己烷-丙酮共沸物，用水萃取分离。 📄见PPT
核心 举例（苯为共沸剂制无水乙醇）：利用三元非均相共沸物+分相器。流程：共沸精馏塔+苯回收塔+乙醇回收塔。 📄见PPT
▾ 第三节 萃取精馏 ⭐⭐⭐
核心 萃取精馏：加入高沸点萃取剂S，选择性改变A、B组分的蒸汽压，增大相对挥发度。α₁₂ = (γ₁ p₁^s) / (γ₂ p₂^s) 📄见PPT
重点 萃取剂作用：①改变原有组分间相互作用；②稀释作用。关键：活度系数比γ₁/γ₂的变化。
重点 Ewell分类选择法：按极性排序：烃→醚→醛→酮→酯→醇→二醇→水。选择极性更类似于重组分的物质作萃取剂，减少重组分挥发度。
重点 萃取精馏特点：两股进料、三个塔段；大量高沸点萃取剂（x_S>0.6）；显热占较大比例；分离调节方法为萃取剂用量+温度。
重点 萃取精馏 vs 共沸精馏比较：共沸剂数目不如萃取剂多；共沸精馏能耗通常更高；共沸精馏操作条件更苛刻；共沸可用于间歇操作；共沸操作温度较低，适合热敏物料。 📄见PPT
了解 加盐精馏：加入无机盐改变相对挥发度。加盐萃取精馏：有机萃取剂+无机盐结合，效果更显著。举例：叔丁醇+水体系加EG+无机盐。 📄见PPT
▾ 第四节 反应精馏 ⭐⭐
重点 反应精馏（RD）：将反应和精馏合二为一。若使用固体催化剂→催化精馏（CD）。代表性应用：MTBE、乙酸甲酯。 📄见PPT
重点 反应精馏优点：克服化学平衡限制；提高选择性；利用反应热；破坏共沸物；简化流程、节省投资。
难点 反应精馏数学模型（MESHR方程组）：在MESH基础上增加化学反应项R_j F_j z_{ij} + L_{j-1} x_{i,j-1} + V_{j+1} y_{i,j+1} − (L_j+S_j)x_{ij} − (V_j+G_j)y_{ij} + ν_i R_j = 0
重点 关键设计参数：反应体积（持液量）、停留时间、催化剂放置方式。与普通精馏不同的参数设定：操作压力、回流比、塔板结构、进料位置。
💨 第四章 多组分吸收和蒸出过程 Absorption & Stripping
▾
▾ 第一节 概述 ⭐⭐⭐
核心 吸收：气体混合物+液体吸收剂→基于溶解度差异→实现分离。蒸出（解吸）：吸收的逆过程。
重点 物理吸收 vs 化学吸收；单组分 vs 多组分吸收；等温 vs 非等温吸收；高浓度 vs 低浓度吸收。
重点 吸收过程设计需考虑因素：气量、组成、温度压力；回收率要求；吸收剂选择；操作压力温度；最小吸收剂用量；平衡级数；热效应；塔径塔高。
▾ 第二节 吸收和蒸出过程流程 ⭐⭐
重点 流程类型：单一吸收塔、串联吸收塔、吸收剂回收再循环、吸收蒸出塔（如烯烃厂脱甲烷塔）。 📄见PPT
▾ 第三节 吸收过程的气液相平衡 ⭐⭐⭐
核心 汽相逸度计算：状态方程法；液相逸度：可凝性组分用活度系数法（Lewis-Randall规则），非凝性组分（超临界组分）用K_i = H_{i,j} / p（亨利定律）。
重点 吸收中关键组分只有一个（精馏有两个：LK和HK）。精馏为双向传质（恒摩尔流假设），吸收为单向传质（流率单调变化）。
重点 吸收热效应：溶解热使液体温度升高，推动力减小。措施：①冷却（塔内设冷却器）；②提高液气比；③冷却入塔气体并减湿。
▾ 第四节 吸收塔内参数分布 ⭐⭐
重点 流量：单向传质→气相和液相总流率均沿塔向下增大（与精馏不同）。温度：显著热效应→沿塔向下升高，很多情况出现温度极大值。 📄见PPT
重点 组成分布：关键组分全塔范围有吸收；轻组分靠近塔顶被吸收；重组分主要在塔底附近吸收。
▾ 第五节 吸收过程的严格计算 ⭐⭐⭐
核心 MESH方程组与精馏类似，但K模型不同：可凝性→K_i = γ_i p_i^s φ_i^s / (φ̂_i p) · exp[V_i^L(p−p_i^s)/(RT)]；非凝性→K_i = H_{i,j}/p
难点 SR法（流量加和法）与BP法的不同：迭代变量和收敛检验函数匹配方案相反。内层/外层循环迭代变量不同。原因：吸收中流量变化是主因，温度由热量平衡确定（非泡点）。 📄见PPT
⚡ 第五章 分离过程的节能、优化及综合 Energy & Optimization
▾
▾ 第一节 分离过程用能特性及热力学分析 ⭐⭐⭐
核心 节能一般原则（第二定律）：高能高用，低能低用，温位合理，阶梯利用。
重点 热力学第一定律分析（数量）：再沸器加入的热量Q_R几乎全部被塔顶冷凝器取走。节能关键：回收利用塔顶蒸汽冷凝潜热；产品和进料显热利用；保温绝热。
重点 热力学第二定律分析（品位）：精馏过程不可逆，再沸器高品位能量→冷却水低品位带走（能量贬质）。节能关键：降低不可逆性、减少高品位能量消耗。
重点 有效能损失原因：①流体流动（压力损失）；②传质（浓度差混合）；③传热（温度差混合）；④外部（换热器排放）。 📄见PPT
了解 不可逆性评价：熵产生、有效能（Exergy）、热力学效率。∑E_{xi,in} = ∑E_{xi,out} + E_L
▾ 第二节 精馏过程操作参数的优化 ⭐⭐
重点 操作压力优化：影响冷凝/加热温度、相对挥发度、塔造价。调节压力是实现热集成的有效手段。
重点 回流比优化：R=(1.1~1.2)R_{min}，总费用（操作费+设备费）最小处为最适回流比。 📄见PPT
重点 进料热状态优化：L' = L + qF，V = V' + (1−q)F。进料热状况直接影响塔运行负荷和稳定性。
▾ 第三节 精馏过程节能技术 ⭐⭐⭐
核心 热泵精馏：通过热泵（输入电功），将塔顶蒸汽低温热源提高温位作为再沸器热源。三种方式：①闭式（外部工质）；②开式A型（塔顶直接压缩）；③开式B型（塔底闪蒸）。 📄见PPT
核心 多效精馏：将总分离任务"切割"为多个，分配到多塔中进行，利用高压塔顶汽相冷凝潜热加热低压塔底。双效精馏节能率约40%。 📄见PPT
重点 节能效果与效数：2效~40%，3效~55%，4效~65%，5效~70%。经济效数受设备投资限制。 📄见PPT
重点 增设中间换热器：精馏段设中间冷凝器（低质冷量代替高品位制冷剂），提馏段设中间再沸器（低质热量代替高品位加热介质）。减少不可逆性。
难点 内部热集成精馏（HIDiC）：从精馏段取出热供提馏段使用（精馏段温度为T_精，提馏段温度为T_提，T_精Q = K·S·ΔT 📄见PPT
难点 热耦合精馏：三组分的分离。直接顺序（AB|C→A|B）和间接顺序（A|BC→B|C）。预分馏塔+主塔消除"再混合"效应。 📄见PPT
难点 隔壁精馏塔（DWC）：将FC塔（完全热耦合）合并于同一塔壳，中间加隔板。比简单塔序列节能30%以上。关键技术：隔板两侧汽体流量精确分配和控制。 📄见PPT
▾ 第四节 分离过程的综合 ⭐⭐
重点 分离序列综合：给定待分离混合物和分离要求，以总费用最小为目标，设计产品分离顺序（流程）。属于MINLP（混合整数非线性规划）问题。
重点 经验规则法：①易分离组分先分离；②按轻到重顺序逐一分离（顺序分离）；③含量大的先分离；④塔顶塔底近等摩尔分配；⑤回收率要求高的最后分离。
重点 五组分烃类分离序列合成举例（C₃, iC₄, nC₄, iC₅, nC₅）：最易分离（C₃）先分离→次易分离近等摩尔→次难分离→最难最后。 📄见PPT
重点 同步考虑热集成：匹配不同温位精馏塔的冷凝器和再沸器。与多效精馏的区别。调节压力是实现塔间热集成的主要手段。
🧪 第六章 其它分离技术 Other Separation Technologies
▾
▾ 第一节 吸附分离 ⭐⭐
重点 吸附分离：分离剂为固体吸附剂，基于不同物质对吸附剂亲和性差异。分离过程包括：吸附+脱附两个过程。
重点 物理吸附（范德华力，可逆，多分子层，吸附热~20kJ/mol）vs 化学吸附（化学键力，不可逆，单分子层，吸附热80-420kJ/mol）。
重点 常用吸附剂：有机（活性炭、大孔树脂等）；无机（硅胶、活性氧化铝、分子筛等）。吸附剂特性参数：比表面积、孔径分布、吸附容量等。
核心 Langmuir吸附等温方程：q = q_m · Kp / (1 + Kp)
重点 变温吸附（TSA）：不同温度下吸附量不同，低温吸附+高温脱附。变压吸附（PSA）：不同压力下吸附量不同，高压吸附+低压脱附。 📄见PPT
重点 固定床吸附：三个区域（饱和区、吸附区、未用区）。透过曲线：破点时间t_b，床层饱和时间t_e。 📄见PPT
了解 模拟移动床（SMB）：通过切换进出料位置模拟固体吸附剂移动，实现连续操作。
▾ 第二节 萃取分离 ⭐⭐
重点 液液萃取：分离均相液体混合物（物料分离剂）。工业原则：能用精馏时不用萃取。萃取用于：沸点相近、形成共沸物、热敏性物质。
重点 液液相平衡条件：f_i^E = f_i^R → x_i^E γ_i^E = x_i^R γ_i^R，分配系数 K_i = γ_i^R / γ_i^E
了解 萃取设备：喷淋塔、填料塔、转盘塔、振动筛板塔等。分散相和连续相选择。轴向混合对萃取操作的影响。 📄见PPT
了解 超临界流体萃取：最常用CO₂（临界温度31℃，临界压力7.38MPa）。特点：兼具气液两性。
▾ 第三节 分子蒸馏 ⭐
了解 分子蒸馏：基于速率的分离技术（不同于平衡级）。在高真空下利用分子运动平均自由程差异实现分离。适用于热敏性、高沸点物质。
了解 与超临界萃取的不同：超临界萃取利用溶剂在超临界状态的特殊溶解能力，分子蒸馏利用分子运动自由程差异。 📄见PPT
